# AniVerse 🎌

AniVerse is a responsive anime discovery website where users can explore anime, search for their favourite shows, browse through results, and view detailed information about individual anime.

## ✨ Features

- Browse anime with posters and titles
- Search for anime
- Pagination for browsing results
- Dedicated anime details page
- View anime information including:
  - Producers
  - Release year
  - Duration
  - Rating
  - Rank
- Clickable anime cards
- Responsive design
- Error handling when anime data cannot be loaded
- Dark-themed anime-inspired interface

## 🌐 API

AniVerse uses the **Jikan API**, an unofficial MyAnimeList API, to fetch anime data dynamically.

API used:

```text
https://api.jikan.moe/v4/anime
```

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Jikan API
- DOM Manipulation

## 🔍 How It Works

The website fetches anime data from the Jikan API using JavaScript's `fetch()` method.

Users can:

1. Browse anime on the homepage.
2. Search for a specific anime.
3. Navigate through different pages using pagination.
4. Click an anime card to open its details.
5. View additional information about the selected anime.
